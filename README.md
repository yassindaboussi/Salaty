## ✨ Overview

**Salaty Time** is a cross-platform desktop application built with **Electron.js** that brings Islamic spirituality to your computer. Whether you're seeking accurate prayer times, Quranic wisdom, or daily Islamic reminders, Salaty Time provides a comprehensive suite of Islamic tools with a beautiful, intuitive interface.

🎯 **What Makes Salaty Special:**
- ⚡ Lightning-fast performance with minimal resource usage
- 🎨 Stunning design with 12 carefully crafted themes
- 🌍 Full multilingual support (Arabic, English, French)
- 📱 Responsive layout that works on any screen size
- 🔒 Privacy-focused - all data stays on your device

## 🚀 Getting Started

### 📋 System Requirements

Before you begin, make sure you have:

🔹 **Node.js** - Version 16.0.0 or higher
🔹 **npm** - Version 7.0.0 or higher
🔹 **Git** - For cloning the repository

> 💡 **Tip:** Check your versions with `node --version` and `npm --version`

### 💻 Installation Steps

Follow these simple steps to get Salaty Time running on your machine:

```bash
# Step 1: Clone the repository
git clone https://github.com/yassindaboussi/Salaty.git

# Step 2: Navigate to the project directory
cd Salaty

# Step 3: Install all dependencies
npm install

# Step 4: Start the application
npm start
```

That's it! 🎉 The app will launch automatically.

### 🔧 Development Mode

For developers who want to contribute or customize:

```bash
# Run with detailed logging for debugging
npm run dev
```

This enables verbose console logging to help you develop and debug.

### 📦 Building & Distribution

To create a compiled version of the app:

```bash
# Build for your current operating system
npm run build

# Build specifically for Linux
npm run build:linux

# Create a distributable package
npm run dist

# Clean up old build files
npm run clean
```

### 📝 Code Quality Tools

Keep your code clean and consistent:

```bash
# Lint all source files for code issues
npm run lint

# Lint only the main process files
npm run lint:main

# Lint only the renderer process files
npm run lint:renderer

# Auto-format all code files
npm run format

# Check formatting without making changes
npm run format:check
```

## ⚙️ How The Application Works

### 🔄 Application Architecture Flow

🔹 **Startup & Initialization**
- Application launches via Electron main process
- Settings are loaded from `settings.json`
- Main window is created and renderer loads
- IPC bridge is established for main-renderer communication

🔹 **Data Flow**
- User interacts with the renderer UI
- Renderer sends IPC messages to main process
- Main process handles logic and external API calls
- Results are sent back to renderer for display

🔹 **Prayer Times Workflow**
1. User's location is determined (from settings or IP detection)
2. Main process requests prayer times from Aladhan API
3. Prayer data is cached locally for offline use
4. Renderer displays prayer times with live countdown
5. Adhan alert is triggered at configured time

🔹 **Theme & Language System**
- User selects theme/language from settings
- CSS variables are dynamically updated
- Renderer is notified and UI updates instantly
- Preference is saved to settings file

### 🔐 Security Architecture

🔹 **Preload Script Security**
- 🛡️ Isolated context bridge between main and renderer
- 🔒 Only whitelisted IPC channels are exposed
- 🚫 No direct file system access from renderer
- 📡 Controlled communication protocol

🔹 **Data Protection**
- 💾 Settings stored locally on user's device
- 🔐 No tracking or telemetry
- 📴 Works offline after initial data load
- 🔄 HTTPS for API communication
